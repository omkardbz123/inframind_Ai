1. Executive Overview & Problem Statement

Transforming educational campus facilities with real-time AI intelligence

Traditional educational campuses suffer from delayed maintenance reporting, lack of automated fault detection, manual dispatch bottlenecks, and missing photographic resolution proof. MIT ACSC CampusCare delivers a unified ecosystem integrating Computer Vision, Real-Time WebRTC Video Nodes, Multimodal Gemini AI, and Physical QR Code Scanning.

⚡ Rapid Reporting

Physical QR scanning auto-populates campus building, room, and asset data directly into Step-3 fault logging in under 5 seconds.

👁️ CCTV Vision AI

Automated frame-by-frame analysis detects dark corridor LEDs and night fixture outages, instantly generating automated work orders.

📄 Verified Resolution

Technicians capture on-site photographic evidence. System auto-generates official signed PDF work orders and sends live Gmail notifications.

2. System Architecture & Component Design

Edge-rendered frontend, real-time client state sync, and Node.js transactional backend

1
User Presentation Layer (PWA + React 18 + Tailwind): Mobile-first UI with responsive dashboards tailored for Students, Teachers, Technicians, Facilities Managers, and the Principal.
2
Hardware & Vision Interfacing: HTML5 WebRTC Camera (getUserMedia) + jsQR Barcode Decoder + Google Gemini Multimodal Vision API.
3
Distributed Reactive State Layer: Zustand State Stores with BroadcastChannel API for instantaneous cross-tab and cross-window sync across all devices.
4
Backend & Notification Layer: Node.js Express Server + Nodemailer + Google SMTP for live email dispatch with attached high-resolution PDF work orders.
5
Edge CDN Delivery: Deployed on Cloudflare Workers globally with Workbox Service Worker precaching for sub-second load times.

3. End-to-End Operational Lifecycle

How maintenance issues travel from initial detection to verified completion

Step 1: Fault Logging & Evidence

Student or faculty scans asset QR tag (or snaps photo / chats with Gemini AI). Asset metadata (Building, Floor, Room, Tag) is auto-populated. User attaches fault photo and submits.

Step 2: Department Triage & SLA

Facilities Manager views incoming complaint on Department Triage queue. Gemini AI computes Urgency Score (0-100) and calculates target SLA deadline (2h for Critical, 8h for High).

Step 3: Technician Dispatch & Repair

Technician receives on-screen notification and task card under Work Orders. Technician clicks Start Work to transition to in-progress and begins on-site hardware troubleshooting.

Step 4: Resolution Proof & PDF Report

Technician logs diagnostic notes, spare parts used, and snaps a live resolution proof photo. System generates official signed PDF work order with both photos and dispatches Gmail confirmation.

4. Gemini Multimodal AI & CCTV Vision Inspector

Proactive failure prevention using machine vision and degradation curves

🎥 Cross-Device CCTV Camera Node

Turn any smartphone into a remote CCTV node (/cctv-node). Transmits live WebRTC camera feed to the Central Control Room for automated continuous monitoring.

💡 Automated Night LED Outage Detection

Analyzes video frames with Google Gemini Vision API to detect dark corridor tube lights, unlit fixtures, and electrical flicker, creating automated priority tickets without manual human intervention.

📈 Predictive Risk Engine

Calculates Mean Time Between Failures (MTBF), operational aging degradation curves, and thermal wear factors to alert technicians before equipment suffers total breakdown.

🗺️ Campus Spatial Risk Heatmap

Visual map of Main Academic Block (MAB), C-Block, and Library showing high-risk infrastructure zones and open work orders by floor and wing.

7. Physical Hardware & Report Generation Pipeline

High-fidelity documentation with dual photographic proof

📷 Dual Photo Evidence in PDF

Every generated PDF work order includes two standardized high-DPI image boxes: Box 1 (Fault Photo logged by Student/Teacher) and Box 2 (Resolution Proof Photo uploaded by Technician).

When tickets are logged or resolved, Node.js + Nodemailer automatically transmits branded HTML notification emails with the physical PDF work order attached directly to the student and manager.
